Cara menulis

Cara paling mudah adalah tombol ✎ Edit atau Mulai lagu baru (ketuk-ketik, tanpa kode). Mode teks ini untuk yang ingin menulis cepat dengan kode alphaTex.

Semua instrumen

  • :4 not seperempat, :8 seperdelapan, :2 setengah, :1 penuh. Berlaku untuk not berikutnya.
  • r = diam (tanda istirahat), | = garis birama, {d} = not bertitik, :8 {tu 3} = triol
  • \title "Judul", \tempo 90, \ts 3 4 (birama 3/4)
  • \track "Nama" = instrumen baru di lagu yang sama (seperti contoh lagu band)
  • {ch "C"} setelah not = nama chord di atasnya

Gitar, bass, ukulele

  • 3.2 = fret 3 di senar 2 (senar 1 = senar paling tipis)
  • (0.1 1.2 0.3 2.4 3.5) = beberapa senar dipetik bersamaan
  • \tuning (G2 D2 A1 E1) = stelan senar dari yang paling tipis (contoh ini bass 4 senar)
  • \chord ("C" 0 1 0 2 3 x) = diagram chord, fret tiap senar, x = tidak dibunyikan
  • 5.3 {h} 7.3 = hammer-on, 5.3 {sl} 7.3 = slide, 7.3 {b (0 4)} = bend

Piano, keyboard, vokal, tiup

  • C4 D4 E4 = nama not + oktaf (C4 = do tengah), F#4 kres, Bb3 mol
  • (C4 E4 G4) = akor (beberapa not bersamaan)
  • \tuning piano atau \tuning voice setelah \track, \lyrics "do re mi" = lirik

Drum

  • Mulai dengan \instrument percussion dan \articulation defaults
  • KickHit (kick), SnareHit, HiHatClosed, HiHatOpen, CrashMediumHit, RideMiddle, HighTomHit, LowFloorTomHit
  • (KickHit HiHatClosed) = dipukul bersamaan

Format ini bernama alphaTex. Lihat contoh lagu untuk pola yang lebih lengkap.

Buka file

Mendukung Guitar Pro 3 sampai 8 (.gp3, .gp4, .gp5, .gpx, .gp) dan MusicXML (.musicxml, .xml, .mxl) untuk semua instrumen: gitar, bass, ukulele, piano, drum, vokal, tiup, dan gesek. Tab, not balok, chord, dan lirik tampil bila ada di file. Partitur dari MuseScore bisa diekspor ke MusicXML lalu dibuka di sini.

Putar & latihan

Ketuk not untuk mulai dari situ, atau seret beberapa birama untuk dipilih lalu nyalakan Ulang untuk melatih bagian itu. Turunkan kecepatan ke 50–75% untuk bagian yang sulit, atau pakai Naik tempo supaya kecepatannya naik sendiri tiap putaran. Tap = ketuk beberapa kali mengikuti ketukan untuk menyamakan tempo. Hitung masuk memberi aba-aba “one, two, three, four” sebelum lagu mulai. Bisukan satu instrumen di menu Instrumen untuk latihan mengiringi. Spasi = putar/jeda. Pengaturan terakhir diingat di perangkat ini.

Menulis tab

Tekan ✎ Edit (atau Mulai lagu baru di menu Ganti lagu), lalu pilih instrumennya di panel.

Gitar, bass, ukulele: ketuk posisi di tab untuk memilih ketukan dan senar, lalu ketuk angka fret. Piano, vokal, melodi: ketuk tuts; setiap tuts menulis satu not lalu maju (nyalakan Akor untuk beberapa tuts sekaligus). Drum: ketuk kotak di kisi untuk tiap pukulan, lalu Salin birama untuk mengulang polanya. Lirik: tombol Lirik, ketik suku kata, Enter atau spasi untuk lanjut ke not berikutnya.

Panjang not dipilih di baris atas; teknik dan nama chord di baris bawah. Di komputer bisa langsung pakai keyboard (daftar tombolnya ada di panel). Tulisan disimpan otomatis di perangkat ini dan bisa diunduh sebagai Guitar Pro.

Nada, kapo, tampilan

Nada −/+ menaikkan atau menurunkan lagu setengah nada untuk semua instrumen (tab ikut menyesuaikan). Kapo untuk gitar dan ukulele: tab dan chord berubah menjadi bentuk yang dimainkan dengan kapo, bunyinya tetap. Tampilan bisa diganti ke not balok, tab, not angka, atau slash (irama saja, untuk pengiring).
